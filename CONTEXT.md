# BluePLM Community – Begriffe

## Community API

Die authentifizierte PHP-Schnittstelle für BluePLM-Clients. Sie ist kein
browserbasiertes Administrationsportal und verlangt für geschützte Aufrufe ein
Anmeldetoken.

## Adminportal

Eine browserbasierte Verwaltungsoberfläche für eine Organisation. Sie ist von
der Community API getrennt und darf deren Zugangsschutz nicht abschwächen.

## Organisation

Die Mandanteneinheit, der Benutzer, Teams, Vaults, Dateien und
Firmenkonfiguration zugeordnet sind.

## Owner

Das verantwortliche Mitglied einer Organisation. Der Owner darf
organisationsweite, sicherheitsrelevante Verwaltungsentscheidungen treffen.

## Administrator

Ein Mitglied mit Verwaltungsrechten innerhalb seiner Organisation, etwa für
Benutzer, Teams, Vault-Zugriffe und die Firmenkonfiguration.

## Mitglied

Ein reguläres Organisationsmitglied. Es erhält ausschließlich die ihm über
direkte oder Team-Vault-Zugriffe zugewiesenen Inhalte und keinen Zugang zum
Adminportal.
